# @seo-autopilot/engine-sdk

The Intelligence Engine SDK.

- `IntelligenceEngine` interface (`analyse` / `recommend` / `automate` / `health`)
- `BaseIntelligenceEngine` scaffold
- `InMemoryEngineRegistry` plugin registry
- Re-exports Event Bus helpers from `@seo-autopilot/shared`

No engine may invent its own top-level structure.
