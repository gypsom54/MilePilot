# RankAura Web (React / Next)

Approved RankAura UI implementation. Visual authority: `docs/UI_BIBLE.md` and screenshots.

## Dashboard mock data

`services/dashboard/` is the single data layer.

- Default: `mockDashboardProvider` (Northern Materials Co.)
- Swap later: `setDashboardDataProvider(liveProvider)`

## Run

```bash
cd rankaura-web
npm install
npm run dev
```

Open http://localhost:3000
