# RankAura Constitution
Version 1.0

## Mission
RankAura exists to help businesses grow.

**We Help Grow Businesses.**

RankAura is not another SEO dashboard. It is an **AI Growth Manager**. Customers should not need to understand technical SEO. RankAura handles complexity in the background while the customer runs their business.

## Core Principle
Every feature must answer:

> Does this help the customer grow without making them work harder?

If not, it does not belong.

## What Customers Buy
Customers buy more enquiries, calls, customers, visibility, revenue, confidence, time and peace of mind—not SEO terminology.

Prefer:
- Growth Plan
- Growth Opportunities
- Website Improvements
- Business Visibility
- Growth Team
- Business Health
- Growth Potential

Avoid leading with:
- SEO audit
- Canonical tags
- Schema
- Robots.txt
- Crawl errors
- Meta optimisation

## Experience
RankAura should feel calm, premium, modern, intelligent, reassuring, spacious and effortless.

It should never feel technical, overwhelming, cluttered, stressful or like a traditional SEO tool.

Whitespace, simplicity and confidence are features.

## Interface Rule
The interface should never make users feel busier than before they opened it.

Every screen should have:
- One purpose
- One primary action
- One clear message
- Minimal supporting detail
- No unnecessary cards
- No visual noise

## Existing UI Protection
IMPORTANT: this repository already contains approved UI, layouts and components.

Treat the existing repository as the current implementation and visual foundation.

Do not redesign approved work from scratch.

Before changing a screen:
1. Review the existing implementation.
2. Preserve approved layouts and components where possible.
3. Improve rather than replace.
4. Maintain the existing visual language.
5. Change only what the current sprint requires.

## AI Philosophy
RankAura should feel like an experienced growth team quietly working in the background.

It may perform or prepare:
- Website analysis
- Competitor research
- Keyword opportunity discovery
- Search-intent analysis
- Technical checks
- Content planning
- Local visibility analysis
- Directory opportunities
- Internal linking
- Authority analysis
- Partnership opportunities
- Growth planning
- Progress monitoring

The customer sees what was found, completed, what needs approval and how it may help growth.

## Dashboard Philosophy
The homepage is not a dashboard. It is a calm daily briefing answering:
1. What happened?
2. What happens next?
3. What needs approval?

Everything else belongs deeper in the product.

## Long-Term Vision
RankAura should feel like a growth partner, not software.

> It quietly grows your business while you get on with running it.
