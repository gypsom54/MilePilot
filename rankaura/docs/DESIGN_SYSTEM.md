# RankAura Design System

## Direction
Premium, minimal, modern, calm, intelligent and trustworthy.

Approved direction (from locked screenshots + React implementation):
- White / near-white grounds
- Ink `#080f1a` for headings and primary buttons
- Muted `#8b95a5` for secondary text
- Soft borders `#e5e7eb`
- Success green `#2eb88a` for analysis ticks
- Soft blue wash for active dashboard nav
- Generous whitespace
- Subtle motion

Use the approved screenshots and existing React/Next tokens as the source of truth.  
Do not replace the palette. Do not adopt the HTML prototype look.

## Typography
Use the current approved typeface.

Prioritise:
- Large confident headings
- Short line lengths
- Clear hierarchy
- Comfortable spacing
- Minimal uppercase
- No dense text blocks

## Buttons
Use one consistent shape, height and primary colour.

Preferred labels:
- Get Started
- Continue
- Launch Growth Plan
- Review
- Approve

## Inputs
Large, clear and calm. Preserve data when navigating backwards. Validate without alarming language.

## Cards
Use only when they clarify grouping. Prefer spacing over card grids.

Avoid heavy shadows, thick borders, excessive glassmorphism and repeated glow effects.

## Animation
Use soft fades, gentle slides, subtle progress and calm stage transitions.

Avoid bouncing, confetti, aggressive glow pulses and constant background motion.

## Responsive and Accessibility
Support desktop, laptop, tablet and mobile.

Maintain contrast, keyboard navigation, focus states, labels, reduced motion and proper headings.
