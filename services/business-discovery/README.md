# @seo-autopilot/business-discovery

Business Discovery Engine — Volume 4 / Sprint 1.

Canonical source of business understanding for SEO AutoPilot.

## Includes

- Domain model (identity, brand, offers, audience, goals, expertise, trust, assets, competitors, questions, constraints, preferences)
- Provenance on every field
- Versioned profile persistence
- Knowledge Graph mappings
- Validation layer
- Event publication
- Capability Manifest
- API handlers
- Enrichment suggestions (confirm-before-canonical)

## Explicitly excluded

- Website crawling
- SEO scoring
- Keyword research
- Content generation
- AI orchestration
- Dashboards
- Opportunity calculations
